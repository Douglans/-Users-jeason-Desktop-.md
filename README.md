 ### 核心目标 
 帮助商家管理微信/企业微信私域客户，记录客户信息、沟通记录、标签分类，解决手动记录混乱、客户流失的痛点。 
 
 ### 技术栈（必须严格遵守） 
 前端：HTML + Tailwind CSS + Alpine.js（轻量框架） 
 后端：Node.js + Express 
 数据库：SQLite（无需额外安装） 
 依赖：express-validator（参数校验）、ejs（模板引擎）、csv-parser（数据导入） 
 
 ### 必做功能（完整实现以下逻辑） 
 1.  客户管理模块： 
     - 客户信息录入（姓名、电话、微信、来源渠道、标签） 
     - 客户列表分页展示（支持按标签/来源/时间筛选） 
     - 客户详情页（查看完整信息、沟通记录） 
     - 批量导入/导出客户数据（CSV格式） 
 2.  沟通记录模块： 
     - 新增沟通记录（时间、内容、跟进状态） 
     - 记录按时间倒序排列 
     - 跟进状态标记（待跟进/跟进中/已完成） 
 3.  标签管理模块： 
     - 自定义标签（添加/删除/修改） 
     - 标签批量分配给客户 
     - 按标签筛选客户 
 4.  数据统计模块： 
     - 客户总数、新增客户数（按日/周/月统计） 
     - 各标签客户占比饼图 
     - 跟进状态分布柱状图 
 
 ### 输出交付物（缺一不可） 
 1.  完整前后端代码（模块化结构） 
 2.  SQLite数据库脚本（客户表、沟通记录表、标签表） 
 3.  package.json（完整依赖） 
 4.  启动命令（npm start） 
 5.  部署说明（本地+云服务器部署步骤） 
 6.  测试用例（验证客户添加、标签管理、数据导出功能） 
 
 按7天开发流程执行，确保交付的代码可直接运行，功能完整无缺失。
